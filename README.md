# TOPIK Quest: Blush Academy

A production-oriented, game-like web app to help learners progress through TOPIK levels 1-6 with a cutesy visual style (blush, white, gold, and cream) and an encouraging mascot.

## Features

- 6 TOPIK levels, each with **15 lessons** (90 total).
- Per-lesson activities:
  - Flash cards
  - Memory matching game
  - Fill in the blank
  - Scenario challenge
- Themed lessons spanning practical and advanced contexts.
- Persistent lesson completion using browser localStorage.
- Responsive layout designed for desktop and tablet/mobile.

## Run locally

Because this is a static app, you can serve it with any HTTP server. Example:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
